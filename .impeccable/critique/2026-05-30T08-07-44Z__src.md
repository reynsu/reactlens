## Priority Issues

### [P0] ANSI escape codes literal in Playwright error display
BrowserPreview.tsx:36 renders test.error raw inside <pre>. Output shows `[2m...[22m` as text. Fix: strip ANSI or parse Locator/Expected/Received into colored spans.

### [P0] Tokenizer dies on React internals — [Function]/[Circular] colored as orange strings
code-render.tsx:25-44 JSON.stringify-truncates objects to 80 chars and renders sentinels as code-string (orange). For real React internals (RouterProvider, hooks), the panel becomes a wall of orange-string that aren't strings. Fix: sentinel-aware coloring (gray italic for [Function]/[Circular]); collapsed-by-default for objects with expand-on-click; type badge before key.

### [P0] Inspector + Diagnostics share one scrolling column
App.tsx:534-549 stacks both inside .panel (col 3). Selecting a tree node expands Props + Hooks; Diagnostics scrolls below the fold. Breaks the redesign's pitch ("diagnose with component context visible"). Fix: 50/50 split rows OR Tabs OR Diagnostics sticky-top.

### [P1] Patch has class="language-diff" but no diff CSS
styles.css:156-159 styles .patch but no rules for .language-diff or +/- prefix coloring. Both lines render same color. Fix: process visualDiffLines into .diff-add/.diff-del spans with green/red bg.

### [P1] Middle column collapses below ~900px viewport
.layout is `300px 1fr 380px` with `min-width: auto`. At 800px viewport, middle column collapses to ~120px (title breaks into vertical noodle). Fix: `min-width: 0` + `minmax()` constraints; sidebar collapse <900px.

### [P1] Zero keyboard navigation
No arrows/j/k for test list, no n/p for failed test, no expand/collapse keys on tree, no command palette. Critical for Product register aimed at devs. Fix: ↑/↓ + j/k in test list, n/p next-failed, →/← in tree, ? cheatsheet.
