## Anti-Patterns Verdict
LLM: not AI-generated. Tree-as-hero is uncopyable (needs the component tree). Memorable now, not just competent. Identity coherent (light browser-window, indigo <=10%, two-family type).
Detector: 2 warnings, BOTH false positives — `overused-font: Inter` (product register permits Inter; DESIGN.md commits it deliberately) and `single-font` (detector parses only index.html link, misses that JetBrains Mono is the hero; dashboard uses two families).

## Priority Issues

### [P1] Footer kbd-hints promise shortcuts not wired
n next failed / cmdK command palette / ? shortcuts shown in footer; only Cmd+F (search), tree arrows, tabs arrows actually wired. Promise-then-fail. Fix: wire n/p + ? at minimum, or remove unwired hints from footer.

### [P1] DiagnosticsPanel still has scattered inline style={{}}
streaming-text pre, applyState messages, git-context line, confidence span all inline-styled instead of classes. Breaks the just-codified DESIGN.md consistency. Fix: extract to classes or Tailwind utilities.

### [P2] RunPicker shows raw UTC timestamps
"2026-05-30 07:57:42Z · /9" per option. Alex needs relative time + inline pass/fail counts ("2h ago · 6/9 passed"). Fix: Intl.RelativeTimeFormat + counts from runId.
